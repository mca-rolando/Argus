# Changelog

All notable changes to ARGUS will be documented in this file.

ARGUS uses a calendar-based version identifier in the form:

```text
YY.MM-RR
```

Where:

- `YY` is the two-digit year.
- `MM` is the two-digit month.
- `RR` is the release sequence for that month.
- Development versions include the `-dev` suffix.
